# Recuperação Git - Cadastro de Alunos

* **Nome do Aluno:** Thamires Gama
* **Nome da Disciplina:** Programação de Computadores
* **Objetivo do Projeto:** Utilização prática do Git e GitHub para controle de versões e colaboração em um projeto.
* **Linguagem Utilizada:** C

## Descrição Breve do Programa
Sistema simples em C para cadastrar e exibir informações básicas (nome, idade e nota) de alunos.

## Como Executar o Programa
1. Compile o arquivo `main.c` com um compilador C (ex: `gcc main.c -o programa`).
2. Execute o binário gerado (`./programa` no Linux/Mac ou `programa.exe` no Windows).
