# Respostas da Atividade

1. **O que é um repositório?**
   É o local onde os arquivos do projeto e todo o histórico de alterações ficam armazenados.

2. **Qual a diferença entre Git e GitHub?**
   Git é a ferramenta local de controle de versão; GitHub é a plataforma web onde hospedamos repositórios Git na nuvem.

3. **Para que serve um commit?**
   Para salvar um ponto no histórico de alterações do projeto com uma mensagem descritiva.

4. **Por que utilizamos branches?**
   Para desenvolver recursos isoladamente sem afetar o código principal (`main`).

5. **Qual a finalidade de um Pull Request?**
   Solicitar a revisão e a integração de alterações de uma branch para outra.

6. **Qual a diferença entre fazer um commit e fazer um push?**
   Commit salva as alterações localmente; push envia os commits para o repositório remoto.

7. **O que acontece quando um Pull Request é realizado?**
   Abre-se uma proposta de fusão para comparar o código, revisar alterações e integrar branches.

8. **Qual a finalidade do merge?**
   Unir o histórico e o código de duas branches.

9. **Por que não é recomendado realizar todo o desenvolvimento diretamente na main?**
   Para evitar bugs ou código quebrado na versão estável do projeto.
